# Max Profit Algorithm

## Project Overview
This project solves a maximum profit problem using Python. The objective is to determine the most profitable combination of theatres, pubs, and commercial parks within a given time limit.

## Property Details
- Theatre (T): Takes 5 time units and earns $1,500 per unit.
- Pub (P): Takes 4 time units and earns $1,000 per unit.
- Commercial Park (C): Takes 10 time units and earns $2,000 per unit.

## Technologies Used
- Python
- Algorithm design
- Problem-solving and optimization

## Example
**Input:** Time = 7

**Maximum Earnings:** $3,000

Possible solutions:
- T: 1, P: 0, C: 0
- T: 0, P: 1, C: 0

## How to Run
1. Install Python 3 if needed.
2. Run `max_profit.py`.
3. Enter the available time when prompted.
4. Review the maximum earnings and possible solutions.
